# 界面设计说明

本次界面根据项目根目录的六张 ChatGPT Image PNG 设计图实现，覆盖登录、首页大盘、设备管理、工单调度、AI 助手和监测数据。

## 公共组件

- src/styles/theme.css：颜色、表格、按钮、卡片、分页与响应式样式。
- src/components/BrandMark.vue：矢量系统标志。
- src/components/PageHero.vue：页面标题和建筑背景。
- src/components/DesignArt.vue：通过 SVG 视口显示原设计图的装饰区域。
- src/components/EmptyState.vue：通用空状态。

public/design 中的 PNG 是用户提供设计图的副本，仅作为背景和插画素材。修改 DesignArt 中的区域配置即可调整显示范围。导航、标题、表格、按钮和输入框均为真实 Vue 组件。

## 数据和交互

- 所有业务数据继续读取现有后端接口，未将设计图中的示例数字、日期或曲线写入应用。
- 设备管理增加与现有分页接口对接的页码和每页条数控件。
- 监测图表支持同类指标切换、缩放、全屏和当前页 CSV 导出，保留缺测断点，按时间正序展示。
- AI 空状态中的问题可直接发送；切换模式或清空对话后，之前请求的回复不会进入新的对话。
- 设计图中的通知、附件等缺少现有接口的操作未添加为无效按钮。

## 本地预览

在 frontend 目录执行 npm.cmd run dev，通过终端显示的本地地址访问。登录和真实业务操作需要启动后端。

本次已使用浏览器模拟接口检查桌面和手机尺寸的六个页面、登录、分页、创建弹窗、监测指标切换及导出、AI 对话和错误状态。模拟数据只存在于独立检查脚本中，不随应用发布；真实数据库写入和模型调用仍需在后端启动后联调。
