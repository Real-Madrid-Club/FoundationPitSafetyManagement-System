### 4.2 健康预测算法（2.5min）⭐

> "我们不只是展示数据，还做了预测——每台设备上方都有一个血条，告诉你还剩多少安全运行时间。"

| 讲什么 | 代码位置 |
|--------|----------|
| 算法流程总览 | `sql/train_model.py` |
| 数据来源：35 万条真实数据 + PitMonitor-TwinBench calibration.json | `sql/calibration.json` |
| SP1 校准数据（P95=2234, mean=1617, 力温相关=0.30） | `calibration.json:22-56` |
| 70/30 训练验证集分割 | `train_model.py:82-88` |
| 线性回归拟合趋势直线 | `train_model.py:91-94` |
| 力温相关性交叉验证（偏差>0.15 则标记异常+风险系数 1.5） | `train_model.py:107-112` |
| 轴力健康度公式：remaining_h / 8760 * 100 / riskFactor | `train_model.py:116-131` |
| 全站仪位移：pos_score(60%) + trend_score(40%)，30mm预警/60mm危险 | `train_model.py:165-200` |
| 温度：均值偏离(40%) + 趋势(30%) + 跳变检测(30%) | `train_model.py:203-260` |
| Java 后端加载（@PostConstruct 读 JSON → Map） | `backend/.../predict/service/HealthPredictionService.java:21-33` |
| 健康度 API（GET /health/{code} / GET /health/all） | `backend/.../predict/controller/HealthPredictionController.java:19-26` |
| 前端拉取 + 渲染血条 | `FoundationPit3D.vue:369-379` `fetchAllHealth()` |

**关键数据**：
- **4P1：仅 6% 健康度** — 轴力当前 1499kN，P95=1875，趋势递增，558 小时后触达阈值
- **FRHY-01：95% 健康度** — 累计位移 2.77mm，距危险阈值 60mm 很远
- 温度传感器检测到跳变次数（如 6501957 达 103 次异常跳变 → 65%）

**强调**：阈值不是瞎编的，来自 **PitMonitor-TwinBench 学术基准数据集** 的 calibration.json。
